# Russian LoRA Fine-Tuning

Пайплайн для параметрически эффективного fine-tuning русскоязычной LLM с использованием LoRA.

## Задача

Цель проекта — адаптировать русскоязычную языковую модель под собственный instruction-style датасет и проверить, может ли LoRA fine-tuning улучшить ответы модели без полного дообучения всех весов.

Проект фокусируется на практическом workflow дообучения:

* подготовка датасета в формате instruction-response;
* загрузка русскоязычной базовой модели;
* применение 4-bit quantization для экспериментов в Google Colab;
* обучение LoRA-адаптеров;
* запуск inference с дообученным адаптером.

## Датасет

Исходный обучающий датасет содержит **8,641 размеченный пример** в формате JSONL.

Полный датасет не включён в публичный репозиторий. Для воспроизводимости и быстрого тестирования в репозитории находится уменьшенный публичный сэмпл.

| Файл               | Описание                                                 |                       Размер |
| ------------------ | -------------------------------------------------------- | ---------------------------: |
| `data_small.jsonl` | Уменьшенный сэмпл исходного instruction-датасета         |                  432 примера |
| `output.jsonl`     | Полный обучающий датасет, использованный для fine-tuning | 8,641 пример, не опубликован |

Формат данных:

```json
{
  "instruction": "Вопрос или задача на русском языке",
  "input": "",
  "output": "Целевой ответ"
}
```

## Метод

В проекте используется **LoRA** — метод параметрически эффективного fine-tuning. Вместо обновления всех весов модели LoRA обучает небольшой набор adapter-параметров, что делает эксперимент более подходящим для ограниченных GPU-ресурсов.

Основная конфигурация эксперимента с QVikhr:

| Параметр        |                                Значение |
| --------------- | --------------------------------------: |
| Базовая модель  | `QVikhr-3-1.7B-Instruction-noreasoning` |
| Quantization    |                                   4-bit |
| LoRA rank       |                                      32 |
| LoRA alpha      |                                      64 |
| Количество эпох |                                       1 |
| Learning rate   |                                  `5e-5` |
| Среда запуска   |                            Google Colab |

## Как запустить

Рекомендуемая среда запуска — **Google Colab** с включённым GPU runtime.

### 1. Склонировать репозиторий

```bash
git clone https://github.com/DMalakhov1/russian-lora-finetuning.git
cd russian-lora-finetuning
```

### 2. Открыть основной ноутбук

Откройте в Google Colab:

```text
QVikhr-3-1.7B_update.ipynb
```

### 3. Установить зависимости

Ноутбук устанавливает необходимые библиотеки внутри Colab. Если проект запускается локально, зависимости можно установить вручную:

```bash
pip install -r requirements.txt
```

### 4. Подготовить датасет

Для быстрого теста используйте:

```text
data_small.jsonl
```

Для полного обучения нужен исходный датасет с той же JSONL-схемой.

### 5. Запустить fine-tuning

Выполните ячейки ноутбука по порядку:

1. подключить Google Drive или загрузить датасет;
2. установить зависимости;
3. загрузить tokenizer и базовую модель;
4. применить LoRA-конфигурацию;
5. запустить обучение;
6. сохранить LoRA-адаптеры;
7. запустить inference на собственных промптах.
